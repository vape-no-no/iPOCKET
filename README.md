# iPOCKET
Web Application for iPhone. Future app will be developed in swift

A pocket "OS" that runs entirely as static files — HTML/CSS/JS only, no server,
no build step. Open `index.html` (or serve the folder however you like) and
it works, including messaging: local storage handles everything on-device,
and an optional GitHub Gist can be wired up in Settings for syncing across
devices or messaging other people.

If you're seeing this in the web app, please wait for the index file to finish
uploading to GitHub Pages.

Three visual themes (Win98 retro / Win11-ish modern / liquid glass) plus a
terminal-styled "hacker" variant, a handful of built-in games, and the usual
pocket-OS trimmings (notes, contacts, weather, a file explorer, etc).
